# Casos de Prueba

## Caso de Prueba 1: Registro de Usuario
**Descripción:** Verificar que un usuario pueda registrarse correctamente.
**Pasos:**
1. Navegar a la página de registro.
2. Completar el formulario con datos válidos.
3. Hacer clic en el botón de registro.
**Resultado esperado:** El usuario es redirigido al dashboard con un mensaje de éxito.

## Caso de Prueba 2: Inicio de Sesión
**Descripción:** Verificar que un usuario registrado pueda iniciar sesión.
**Pasos:**
1. Navegar a la página de inicio de sesión.
2. Ingresar credenciales válidas.
3. Hacer clic en el botón de inicio de sesión.
**Resultado esperado:** El usuario es redirigido al dashboard.

## Caso de Prueba 3: Recuperación de Contraseña
**Descripción:** Verificar que un usuario pueda recuperar su contraseña.
**Pasos:**
1. Navegar a la página de recuperación de contraseña.
2. Ingresar el correo electrónico registrado.
3. Hacer clic en el botón de enviar.
**Resultado esperado:** Se envía un correo con instrucciones para recuperar la contraseña.

## Caso de Prueba 4: Visualización de Reportes
**Descripción:** Verificar que los reportes se muestren correctamente en el dashboard.
**Pasos:**
1. Iniciar sesión como usuario.
2. Navegar a la sección de reportes.
**Resultado esperado:** Los reportes se muestran correctamente.

## Caso de Prueba 5: Creación de Reportes
**Descripción:** Verificar que un usuario pueda crear un reporte.
**Pasos:**
1. Navegar a la sección de reportes.
2. Hacer clic en "Crear Reporte".
3. Completar el formulario y enviarlo.
**Resultado esperado:** El reporte se crea y aparece en la lista de reportes.

## Caso de Prueba 6: Asignación de GPS
**Descripción:** Verificar que un administrador pueda asignar un GPS a un vehículo.
**Pasos:**
1. Navegar a la sección de GPS.
2. Seleccionar un vehículo y un GPS.
3. Confirmar la asignación.
**Resultado esperado:** El GPS se asigna correctamente al vehículo.

## Caso de Prueba 7: Visualización de Usuarios

## Caso de Prueba 9: Eliminación de Usuarios
**Descripción:** Verificar que un administrador pueda eliminar un usuario.
