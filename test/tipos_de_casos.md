# Tipos de Casos de Prueba

1. **Funcionales:**
   - Registro de usuario.
   - Inicio de sesión.
   - Recuperación de contraseña.
   - Creación de reportes.
   - Asignación de GPS.

2. **No Funcionales:**
   - Tiempo de respuesta en la visualización de reportes.
   - Carga de mapas en la sección de GPS.

3. **De Seguridad:**
   - Verificación de contraseñas seguras.
   - Protección contra ataques de fuerza bruta en el inicio de sesión.

4. **De Integración:**
   - Comunicación entre el backend y el frontend para la visualización de reportes.
   - Integración de mapas con la API de GPS.

5. **De Regresión:**
   - Verificar que las funcionalidades existentes no se vean afectadas tras cambios en el sistema.
